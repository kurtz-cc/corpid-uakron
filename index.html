Demo · Structure Only

Course materials, in one place.

This is a working demo, not a finished site. Just testing whether a simple, standalone hub is worth building out for real. Reference examples, lecture decks, and the course schedule will eventually live here instead of scattered across email and Drive.

What this replaces

Brightspace can't reasonably host the visual reference material this course depends on: brand guideline examples, process books, and similar files aren't practical to make accessibility-compliant, and linking out from Brightspace isn't a clean workaround either. This site is meant to sit entirely outside that system, referenced quietly from the syllabus rather than embedded as an official course link.

What's here so far

Reference Library Placeholder structure for brand guideline examples, process book examples, the typographic & production checklist, Pantone libraries, and project timeline examples.
Presentations Placeholder structure for lecture decks, once the deck template and Section 2 course-structure decisions are settled.
Schedule Real, already-confirmed course dates for Fall 2026. Everything else on this page is a stand-in.
